# Laveck Links

Árvore de links do streamer Laveck, criada com HTML, CSS e JavaScript puro.

## Rodar localmente

```bash
python3 -m http.server 4180
```

Depois, abra <http://127.0.0.1:4180/>.

## Estrutura

- `index.html` — estrutura e conteúdo da página.
- `style.css` — cenário pixel-art, responsividade e componentes visuais.
- `script.js` — compartilhamento, alternância de clima e feedback dos links.

As URLs das redes estão como `#` até serem substituídas pelos links oficiais.
